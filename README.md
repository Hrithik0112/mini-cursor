# Mini Cursor - Minimalist Cursor Clone

A minimalist replica of Cursor editor with mock AI features.

## Features

- Monaco Editor with syntax highlighting
- File explorer with mock files
- AI panel with streaming responses
- Mock RAG context retrieval
- Fake agent workflow visualization
- Code edit application with diff

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
